October's sentence tagging is the first, deliberately narrow version of the same underlying idea.

At that stage:

**text → identifiable components/meaning → structured representation**

So the user only sees it operating on documents and sentences.

Later, Space-time generalizes the same principle from text to:

**text + components + entities + relationships + state + events + geometry + time**

That means the October product is not a different product that later gets replaced.

It is the **textual precursor of Space-time**.

The audience learns the fundamental interaction first, without being told the full abstraction behind it.
