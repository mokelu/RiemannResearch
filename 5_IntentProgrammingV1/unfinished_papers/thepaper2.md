# Chapter 2 — Intent Programming

## 2.1 What Is Intent Programming?

**Intent programming is expressing what you want to happen through the things involved.**

Instead of telling a computer exactly how to perform a task, you describe the desired outcome.

For example:

```text
When the button is pressed, tell me.
```

A traditional program would require code for detecting the button press and then sending a message.

Intent programming starts with the intention itself.

---

## 2.2 First-Person Programming

Intent programming treats the things in a system as **computational selves**.

So instead of thinking:

```text
The program controls the button.
```

we can think:

```text
Button:
    When I am pressed, tell AI.
```

The button is now a participant in the computation.

This is why intent programming can also be described as **first-person programming**.

The instruction is expressed from the perspective of the thing performing it.

---

## 2.3 The World Becomes Programmable

A system can contain many computational selves:

```text
Button
Chart
Spreadsheet
Workspace
AI
```

They can communicate and respond to one another.

For example:

```text
Button → tell → AI
Chart → tell → Button
Workspace → tell → Chart
```

The programmer is therefore not only writing procedures.

They are describing how the things in the world should behave and interact.

---

## 2.4 Intent Becomes Symphony

The human expresses an intent.

AI transforms that intent into a **Symphony**.

The Symphony describes the interaction between the computational selves.

```text
Intent
  ↓
AI
  ↓
Symphony
  ↓
Maxi
  ↓
Finite Selves
  ↓
World
```

The Symphony is similar to a musical score.

It describes what the different participants should do and how they should interact.

Maxi then coordinates its execution.

---

## 2.5 The Key Idea

Intent programming can therefore be reduced to one idea:

> **Instead of programming the computer directly, program the world by giving its computational selves intent.**
