# Chapter 7 — Universal Computational Substrate

## 7.1 What Is the Universal Computational Substrate?

A finite self has a **Universal Turing Machine (UTM)** as its general computational substrate.

The purpose of the UTM is simple:

> **It gives the finite self a universal place to hold and execute a program.**

The UTM does not need to understand every kind of computation itself.

Instead, the program can refer to capabilities that are available to the self.

```text
FINITE SELF
│
└── UTM
     │
     └── Program
          │
          ├── Algebra capability
          ├── CEP capability
          ├── AI capability
          ├── Probability capability
          └── other capabilities
```

## 7.2 Capabilities

A finite self can participate in any Symphony for which the required capability is available.

For example:

```text
Algebra capability   → deterministic computation
CEP capability       → event and temporal computation
AI capability        → reasoning
Probability          → probabilistic computation
```

The finite self does not need a separate machine for every possible use.

It needs a universal substrate and access to the capabilities required by the program.

## 7.3 The Program Can Be General

A Symphony may require several different kinds of computation:

```text
When Button is pressed
within 10 seconds
after Chart crossed SMA
tell AI.
```

The program can therefore refer to different capabilities.

The UTM holds the program while the relevant capability engines perform their respective computations.

The results return to the program, which continues executing.

## 7.4 Completeness

This provides a way to think about the generality of a finite self.

A finite self is not limited to the capabilities that were known when it was created.

When a new capability is added, new Symphonies become possible.

```text
New capability
      ↓
Existing finite selves
      ↓
New possible Symphonies
```

The identity of the self does not have to change.

A Button remains a Button.

A Chart remains a Chart.

The universal substrate gives them the ability to participate in increasingly broad computations.

## 7.5 The Key Idea

> **The UTM gives every finite self a universal computational substrate, while capability engines determine what kinds of computation it can actually perform.**
