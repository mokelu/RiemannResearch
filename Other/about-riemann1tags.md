Riemann 1 Tags are the tagging system we use to turn language into structured, machine-readable event-drive interactive language.

They have three layers:

```text
1. Atomic Tags
   VARIABLE
   FUNCTION
   RELATION
   SET

2. Sentence Tags
   FACT
   OBSERVATION
   DEFINITION
   CHOICE
   STRATEGY
   GOAL
   CLAIM
   QUESTION
   OBJECTION
   CONSEQUENCE
   ASSUMPTION
   EVIDENCE
   INFERENCE
   HYPOTHESIS
   PREDICTION
   PREMISE
   CONCLUSION
   CONDITION
   EVENT
   CAUSE
   EFFECT
   ANSWER
   INSTRUCTION
   INTENT
   CONSTRAINT
   REQUIREMENT

3. Grammatical Tags
   PUNCTUATION
   COMMA
   PERIOD
   QUESTION_MARK
   EXCLAMATION_MARK
   COLON
   SEMICOLON
   PARENTHESIS
   BRACKET
   BRACE
   QUOTATION
   APOSTROPHE
   DASH
   HYPHEN
   ELLIPSIS
   SLASH
```

Atomic and grammatical tags apply to parts inside a sentence, while a sentence itself receives just one sentence tag describing what the sentence itself is doing.
