# The role of JEV

The AI writes the structure: sentences, tags, and connections. But these are only suggestions. When the AI says “this implies that,” it does not know whether the connection is actually valid.

JEV checks that.

```text
"John is a dog" → "John has four legs"       ✓
"John has four legs" → "John is an animal"   ✗
```

The second connection needs another fact: “All dogs are animals.” Because each claim and connection is explicit, JEV can check them one by one instead of letting a weak link hide inside a paragraph.

The jobs are simple:

```text
AI     → writes the structure
Shape  → checks that the structure is valid
JEV/LAYA/Presto → checks in real time whether the reasoning holds
User   → sees what passed, failed, or is still unchecked
```

As the AI writes, JEV/Laya/Presto checks the structure in real time. It does not wait for the entire response to finish: when a sentence or connection is completed, JEV can immediately examine it and mark it as supported, rejected, or unchecked. If JEV finds a problem, that feedback can be sent back to the AI so it can correct the affected part while it is still writing.
