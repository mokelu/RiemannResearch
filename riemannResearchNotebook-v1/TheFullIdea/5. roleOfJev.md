# The role of JEV

The AI writes the structure: sentences, tags, and connections. But these are only suggestions. When the AI says “this implies that,” it does not know whether the connection is actually valid.

JEV checks that.

```text
"John is a dog" → "John has four legs"       ✓
"John has four legs" → "John is an animal"   ✗
```

The second connection needs another fact: “All dogs are animals.” Because each claim and connection is explicit, JEV can check them one by one instead of letting a weak link hide inside a paragraph.

The jobs are simple:

```text
AI     → writes the structure
Shape  → checks that the structure is valid
JEV/LAYA/Presto → checks in real time whether the reasoning holds
User   → sees what passed, failed, or is still unchecked
```

As the AI writes, JEV/Laya/Presto checks the structure in real time. It does not wait for the entire response to finish: when a sentence or connection is completed, JEV can immediately examine it and mark it as supported, rejected, or unchecked. If JEV finds a problem, that feedback can be sent back to the AI so it can correct the affected part while it is still writing.

Yes. I think this is the cleaner answer.

You are moving the job of constructing the reasoning structure to the AI, instead of hard-coding the entire reasoning graph yourself.

```text
USER
 ↓
AI
 ├── sentence 1 → ASSUMPTION
 ├── sentence 2 → STRATEGY
 ├── relation 1→2 → SUPPORTS
 ├── sentence 3 → CONSEQUENCE
 └── relation 2→3 → LEADS_TO
          ↓
   REASONING GRAPH
          ↓
         JEV
```

So the AI is effectively saying, as it generates:

```text
A₁: "John is a dog."           [ASSUMPTION]

R₁: A₁ ──SUPPORTS──> C₁

C₁: "John has four legs."      [CONSEQUENCE]
```

Then Riemann does not need a giant table saying:

```text
ASSUMPTION can SUPPORT STRATEGY
ASSUMPTION can CONSTRAIN GOAL
...
```

Instead, the AI proposes the structure, and JEV evaluates the actual relation:

```text
JEV(
  A₁,
  SUPPORTS,
  C₁
)
```

That gives you a very important division:

```text
AI
= constructs / tags the reasoning structure

Riemann
= stores the structure

JEV
= deterministically evaluates the structure
```


Then JEV takes that relation and evaluates it:

```text
JEV(ASSUMPTION, IMPLIES, CONSEQUENCE)
```

And only after that do we ask JEV for a judgment:

```text
Noul   → true / false
Choice → {true, false, unknown}
Score  → strength of support
```

Now the JEV output can be:

```text id="29164"
Noul   →  TRUE / FALSE
Choice →  {true, false, unknown}
Score  →  strength of support
```

So the important distinction is:

```text id="43517"
"John is a dog."
        ↓
     GIVEN
        ↓
       JEV
        ↓
"John has four legs."
        ↓
 Noul / Choice / Score
```

JEV is not deciding that “John is a dog” should be an assumption.
The system already knows that because we tagged and supplied it as `ASSUMPTION`; JEV is evaluating what follows from it.
