The entire unit of what the AI is writing is a JSON. This is what it is always writing out. Like this:

```js
{
  nodes: [
    {
      id: "n1",
      text: "Inflation came in higher than expected.",
      tag: "FACT"
    },
    {
      id: "n2",
      text: "Bond yields rose.",
      tag: "CONSEQUENCE"
    },
    {
      id: "n3",
      text: "The market fell.",
      tag: "EFFECT"
    }
  ],

  relations: [
    {
      from: "n1",
      relation: "causes",
      to: "n2"
    },
    {
      from: "n2",
      relation: "causes",
      to: "n3"
    }
  ]
}
```

That is what we expect from the AI. Not a paragraph — this. Every answer it
gives, it writes out as JSON like this one: the sentences, the tag it picked
for each sentence, and the connections it picked between them, with the names
it gave them.
